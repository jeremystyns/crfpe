    Ouvrez un fichier .json (projet enregistré) ou un fichier .html exporté par l’Atelier Appli : vous pourrez le modifier.

    Tout reste sur votre ordinateur : aucun compte, aucun serveur, aucune IA.

    Télécharger l’appli

    Vous obtenez un seul fichier HTML autonome (pages, images, polices et styles inclus). Aucune base de données n’est nécessaire.

      Fichier : index.html

      Comment le mettre en ligne ?

      1. Sur votre serveur ou votre hébergeur : déposez index.html dans un dossier, par exemple /appli-accueil/. L’adresse sera https://votre-site.fr/appli-accueil/.
      2. Gratuitement : GitHub Pages, Netlify Drop (glisser-déposer du dossier) ou Cloudflare Pages.
      3. Sur un intranet ou une clé USB : le fichier s’ouvre aussi par double-clic. Les vidéos YouTube et certains formulaires exigent une adresse https://.
      4. Documents PDF : placez-les à côté (documents/reglement.pdf) et saisissez ce chemin dans un bloc « Liens et documents ».
      5. QR code : générez-en un depuis l’adresse finale avec le générateur de votre choix, pour l’afficher dans vos locaux.

      Ce fichier contient aussi votre projet : vous pourrez le rouvrir dans l’Atelier (« Mes applis », puis « Ouvrir un fichier ») pour le modifier plus tard.
