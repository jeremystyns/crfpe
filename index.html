    Reprendre un travail existant

    Ouvrez un fichier .json (projet enregistré) ou un fichier .html exporté par l’Atelier Appli : vous pourrez le modifier.

    🔒 Tout reste sur votre ordinateur : aucun compte, aucun serveur, aucune IA.

    Télécharger l’appli

    Vous obtenez un seul fichier HTML autonome (pages, images et styles inclus). Aucun serveur de base de données n’est nécessaire.

      Fichier : index.html

      Comment le mettre en ligne ?

      1. Sur votre serveur / hébergeur (OVH, o2switch, serveur du centre…) : déposez index.html dans un dossier, par exemple /appli-accueil/. L’adresse sera https://votre-site.fr/appli-accueil/.
      2. Gratuitement : GitHub Pages, Netlify Drop (glisser-déposer du dossier), Cloudflare Pages ou le « pages perso » de votre établissement.
      3. Sur un intranet ou une clé USB : le fichier s’ouvre aussi par double-clic. Les vidéos YouTube et certains formulaires exigent une adresse https://.
      4. Documents PDF : placez-les à côté (documents/reglement.pdf) et saisissez ce chemin dans un bloc « Lien ».
      5. QR code : générez-en un depuis l’adresse finale avec n’importe quel générateur (par exemple dans LibreOffice, ou qrcode-monkey.com) pour l’afficher dans vos locaux.

      💡 Ce fichier contient aussi votre projet : vous pourrez le rouvrir dans l’Atelier (« Mes applis › Ouvrir un fichier ») pour le modifier plus tard.
